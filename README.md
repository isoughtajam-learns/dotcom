# gautamjoshi.com

## What's here

The landing page is plain HTML/CSS/JS (tile-grid background, layout, type,
color) — no build step needed for it. `/writing` is generated by
[Eleventy](https://www.11ty.dev/) from markdown files at build time,
including `feed.xml`.

```
/
  index.html            landing page (passed through by Eleventy as-is)
  style.css             all styles (design tokens at top as CSS variables)
  tiles.js              populates + staggers the animated background grid
  _includes/
    base.njk            shared HTML shell (head, tile-grid div, script tag)
    post.njk             post layout, extends base.njk
  writing/
    index.njk            writing index, lists collections.posts
    feed.xml.njk          RSS feed, generated from post frontmatter
    posts/
      posts.json          directory data: layout + permalink for all posts
      hello-world.md       a post
  .eleventy.js           Eleventy config
  _site/                 build output (gitignored)
```

## Writing a new post

Add a markdown file to `writing/posts/`:

```yaml
---
title: "Post Title"
date: 2026-08-15
summary: "One or two sentences that make someone want to read this."
---

Body in markdown.
```

That's it — `posts.json` in the same folder gives it the `post.njk` layout
and a `/writing/<slug>/` permalink automatically. It'll show up in
`/writing/` and in `feed.xml` on the next build.

## Building

```
npm install
npm run build   # writes to _site/
npm run dev     # local server with live reload
```

Cloudflare Pages: build command `npm run build`, output directory `_site`.

## Tile background

Currently uses generated placeholder gradients (see `tiles.js`) standing in
for real "washed out" project/photo tiles. Swap `placeholderTones` for actual
image URLs once you have a set of images you want in rotation — the CSS
`.cell` class already expects `background-image`.

## Subdomains

Various subdomains (e.g. `irltransit.gautamjoshi.com`) is a separate
project with its own DNS record, entirely decoupled
from this repo. This root site only links out to them.
